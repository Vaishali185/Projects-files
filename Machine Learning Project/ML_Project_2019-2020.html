When using a simple training and test set split to select a model, the test set error may give an overly optimistic estimate of the model's performance, because the parameters were selected for best performance on the test set. Because of this, the common approach is to use a split with 3 sets: training set, validation set, and test set. Cross-validation :- Splittng the data into 3 parts can reduce the amount of data available for training the model and also the estimated performance can vary a lot over the different training and validation splits. One possible solution for these problems is the K-fold cross-validation procedure. It consists of dividing a data set in K parts rather than using the fixed split of training and validation data. it consists of dividing a data set in K parts, K − 1 of which are used for training and one of them used for validation. The process is repeated K times, and every time a different part of the data set for the validation is used.

Diagnosing high bias/variance problemsTwo possible problems with the trained model are high bias and high variance. High bias models cannot represent the target hypothesis well which leads to the high error rate. On the other hand, High variance models tends to overfit the training data which results in the poor generalization. Learning curves are an easy way of determining whether a model is suffering from high bias or high variance. Learning curves plot the errors on the training set and the error on a validation set which is an estimate for generalization error for different sizes of training sets such as using 50, 100, 150, 200,.. samples for training.
